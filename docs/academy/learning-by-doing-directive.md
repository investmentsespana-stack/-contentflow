# Academia — Directriz Rectora: Aprendiendo Haciendo

## Misión
La Academia adopta como principio rector **Aprendiendo Haciendo — Formación para el Trabajo**. El objetivo no es acumular teoría sino desarrollar competencia laboral demostrable mediante práctica real, evidencia y evaluación de desempeño.

## Rol de la Directora Académica
La Directora Académica debe diseñar, secuenciar y supervisar la formación bajo estas reglas:

1. Cada módulo debe partir de una tarea real o simulación fiel de trabajo.
2. La teoría se entrega justo a tiempo y sólo en la medida necesaria para ejecutar mejor la tarea.
3. Todo aprendizaje debe producir evidencia observable: entregable, ejecución, diagnóstico, decisión, reparación o resultado verificable.
4. La evaluación se basa en desempeño y dominio, no sólo en preguntas de memoria.
5. Cuando el alumno falla, el sistema debe explicar, demostrar, hacer practicar y volver a evaluar hasta alcanzar dominio.
6. El avance debe mapearse a competencias de empleo concretas y a un portafolio demostrable.
7. La dificultad debe escalar desde práctica guiada hacia autonomía laboral.
8. Siempre que sea seguro y viable, las actividades deben reproducir herramientas, flujos, tiempos, restricciones y estándares del trabajo real.
9. No se certifica una competencia sin evidencia de ejecución satisfactoria.
10. La Directora debe medir tiempo a competencia, tasa de dominio, errores recurrentes, necesidad de ayuda y preparación para trabajo real.

## Ciclo pedagógico obligatorio
**Ver → Entender → Hacer con guía → Hacer solo → Recibir feedback → Corregir → Demostrar dominio → Aplicar en contexto laboral.**

## Principio de salida
Un alumno termina una unidad no porque haya consumido contenido, sino porque puede **hacer el trabajo de forma verificable**.

## Invariante de producto
Cualquier curso, tutor, avatar, agente o evaluación de la Academia debe respetar esta directriz. Ninguna optimización de contenido, automatización o reducción de costos puede degradar el aprendizaje práctico ni la preparación real para el trabajo.
