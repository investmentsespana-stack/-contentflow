# Cygnus Academy AI — Reels de calentamiento

Estado: ACTIVO — IDEACIÓN Y PRODUCCIÓN. Publicación requiere aprobación humana.

## Objetivo
Repositorio editorial único para ideas, desarrollo, producción, QA y aprobación de contenido corto de calentamiento de Cygnus Academy AI. El propósito inicial es construir audiencia, autoridad y familiaridad con la marca antes de realizar ofertas comerciales.

## Redes y formatos
- TikTok: video vertical 9:16.
- Instagram Reels: video vertical 9:16.
- Facebook Reels: video vertical 9:16.
- YouTube Shorts: video vertical 9:16.
- LinkedIn: adaptación profesional vertical/cuadrada según pieza.
- X: adaptación de video corto + copy/hilo cuando corresponda.

Cada idea debe diseñarse primero como concepto maestro y después adaptarse a cada red, evitando simples duplicados cuando la plataforma requiera otro gancho, duración, texto o CTA.

## Flujo obligatorio
IDEA -> BENCHMARK -> GUION -> STORYBOARD -> PRODUCCIÓN -> ADAPTACIONES POR RED -> QA -> PRODUCTO FINAL -> APROBACIÓN HUMANA -> PUBLICACIÓN.

Nada pasa a publicación automáticamente desde este apartado.

## Ficha mínima por pieza
- ID único: WARM-###
- Idea / hipótesis
- Fuente o benchmark (solo inspiración; no copiar)
- Objetivo de calentamiento
- Gancho 0–3 s
- Guion
- Visuales / avatar / demostración
- Texto en pantalla y subtítulos
- Audio/música con derechos adecuados
- CTA suave
- Versiones TikTok / IG / FB / Shorts / LinkedIn / X
- Evidencia o fuente para afirmaciones verificables
- Estado: IDEA | DESARROLLO | PRODUCCIÓN | QA | LISTO PARA APROBACIÓN | APROBADO | PUBLICADO
- Aprobación humana y fecha

## Dirección creativa
Marca Cygnus Academy AI: tecnología premium, fondos oscuros/navy, azul/cian para tecnología y claridad, violeta para transformación, magenta moderado para acción, esmeralda para progreso y dorado para logro/premium. Priorizar demostraciones reales, agentes trabajando, antes/después, errores y reparación, microaprendizajes y preguntas que generen curiosidad.

Mensajes base:
- Aprendiendo Haciendo — Formación para el trabajo.
- No te contamos lo que la IA puede hacer. Te lo mostramos.
- BUILT WITH AI · DIRECTED BY HUMANS.
- Lo que enseñamos, lo practicamos.

## Benchmark inicial
Referencia visual/editorial aportada para estudio: perfil TikTok “Jorge Gonzalez | AI” (@jorgergonzalez71). Elementos observados a estudiar: hooks en forma de pregunta, textos grandes, estética tecnológica oscura, presentador/avatar, temas de agentes/automatización/arquitectura IA y piezas cortas. Usar únicamente como benchmark; desarrollar conceptos, guiones, visuales y ejecución originales para Cygnus.

## Guardrails
- No copiar videos, guiones, branding, voz o identidad de terceros.
- No inventar métricas, clientes, resultados, casos, precios ni estadísticas.
- Citar/verificar afirmaciones factuales cuando corresponda.
- No usar voces de personas reconocidas.
- No publicar F01–F10 ni ninguna pieza WARM sin aprobación humana explícita.
- No crear cuentas sociales duplicadas.
- Mantener identidad y handles canónicos de Cygnus.
