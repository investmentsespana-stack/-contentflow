# Cygnus Academy AI — Deep Funnel / HIR Content System V1

Status: CANONICAL_EDITORIAL_STANDARD / NOT_PUBLISHED
Date: 2026-09-02
Owner: Social Ops — Cygnus

## Permanent rule

Every social asset must encode one coherent path:

`WHO -> PROBLEM -> INTEREST -> RESULT -> FUNNEL STAGE -> NEXT ACTION`

Permanent editorial constraint:

`1 content = 1 cluster + 1 primary intention + 1 problem + 1 result + 1 funnel stage`

No Reel, Short, Post or carousel is treated as an isolated piece. Organic strategy remains active. Paid campaigns and mass publication remain closed until separately authorized.

## Required metadata before production

Every content item must register before production:
- Interest Cluster
- Broad interest
- Mid-level interest
- Deep intent
- Work problem
- Promised result
- Funnel stage
- CTA
- Visual evidence
- Target persona / WHO
- Next destination
- Measurement target

If one of these fields is missing, status is `BLOCKED_EDITORIAL_SCHEMA`.

## Canonical Cygnus clusters

### CLUSTER A — IA PARA EL TRABAJO
Productivity, communication, documents, research, time, daily work tasks.

### CLUSTER B — APRENDER IA
Practical learning, professional prompting, competencies, Aprendiendo Haciendo, Cygnus Starter.

### CLUSTER C — AUTOMATIZACIÓN
Processes, workflows, integrations, automation and repeatable execution.

### CLUSTER D — IA PARA NEGOCIOS
Business efficiency, OPC diagnosis, repetitive processes, friction reduction, measurable operating improvement.

### CLUSTER E — AGENTES Y SISTEMAS IA
Agents, Director Orquestador, connected AI capabilities, coordination, advanced systems.

## Multimodal consistency gate

For each video, the same concept must be recognizable in:
- teacher/avatar/voice;
- on-screen text;
- visual demonstration;
- caption;
- CTA;
- destination.

RARA must reject a piece when the spoken topic, visual proof, caption and CTA encode different intentions.

Canonical principle:

> Never claim that AI can do something when we can show it happening.

Priority evidence: teacher/avatar + real screen, real workflow, dashboard, document, research, project, Director Orquestador, Skool, Cygnus environment, before/after or verifiable result.

## Video structure

Default 45–55s architecture:
- 0–3s: strong hook.
- 3–10s: problem.
- 10–30s: demonstration/evidence.
- 30–45s: explanation.
- 45–55s: result.
- Final: one CTA.

Also prepare a 20–35s short version. Authority topics may use 60–120s when evidence warrants it.

## Funnel measurement standard

### Top
- Reach
- 3-second views
- Early retention

### Mid
- 50%+ playback
- Profile visits
- Saves
- Shares

### Deep
- Website/Skool click
- Community entry
- Starter start
- Starter completion
- Future upgrade

A piece is not declared a winner from views alone. Winning content is the content that produces deeper progression relative to its funnel role.

## Social SEO standard

Caption must naturally repeat the central semantic concept using:

`problem + AI + work/business context + result`

No generic “future of AI” captions when the piece is about a concrete workflow. Hashtags are secondary. Primary semantic signal must be carried by voice, on-screen text, demonstration, caption, CTA and user behavior.

## Production gate

Before RARA may mark a piece `READY_FOR_APPROVAL`, verify:
1. one cluster only;
2. one primary intention only;
3. one work problem only;
4. one promised result only;
5. one funnel stage only;
6. multimodal semantic consistency;
7. visual evidence is authentic/verifiable;
8. caption matches the same concept;
9. CTA advances exactly one next action;
10. no unsupported performance claim;
11. no confidential/sensitive data;
12. correct platform/account target;
13. publication remains separately gated.

## Learning loop

After publication is separately authorized, Director must feed observed signals back into the next content lot:

`content ID -> cluster -> retention -> mid-depth behavior -> deep action -> inferred audience interest -> next content hypothesis`

The purpose is to learn which semantic paths move users through:

`social discovery -> Cygnus profile -> Skool/community -> Starter -> deeper Cygnus learning path`
