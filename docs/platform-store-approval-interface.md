# PlatformStore Approval Record Interface

The canonical contract is defined in `src/platform/platform-store.ts`.

## Read method

```ts
read<T>(key: string, scope: StoreScope): Promise<T | null>
```

For approval records, callers MUST use `scope = 'approvals'` and the canonical key generated by `approvalStorageKey(changeId)`.

## Approval helper

```ts
readApprovalRecord(
  store: PlatformStore,
  changeId: string,
): Promise<ApprovalRecord | null>
```

`readApprovalRecord` resolves the storage key as `approval:${changeId}` and invokes:

```ts
store.read<ApprovalRecord>(`approval:${changeId}`, 'approvals')
```

## Return type

`Promise<ApprovalRecord | null>` where `null` means no approval record exists for the requested change.

## Usage

```ts
const approval = await readApprovalRecord(store, changeId);
if (!approval || approval.status !== 'approved') {
  return false;
}
return true;
```

Consumers MUST NOT call undefined methods such as `get_approval_record()` or invent alternate approval scopes. This file and `src/platform/platform-store.ts` are the source of truth for approval-record reads.
