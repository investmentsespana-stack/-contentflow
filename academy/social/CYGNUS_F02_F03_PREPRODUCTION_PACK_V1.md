## F02 — IA PARA EL TRABAJO

### Deep Funnel contract
- Cluster: A — IA para el trabajo
- WHO: worker/professional using ChatGPT superficially
- Primary intention: move the viewer from tool-use thinking to task-design thinking
- Problem: using ChatGPT without structuring the work/task
- Result: understand how to turn one real task into a verifiable AI-assisted workflow
- Funnel stage: Discovery
- CTA: identify one real task you currently do with AI

### Hook
“Saber usar ChatGPT no significa saber trabajar con IA.”

### 45–55 s master script
0–3 s — Hook: “Saber usar ChatGPT no significa saber trabajar con IA.”
3–10 s — Problem: “Porque abrir una herramienta y pedirle algo no define el trabajo, el criterio ni el resultado que necesitas.”
10–30 s — Evidence/demo: show one authentic work task. First show the loose/unstructured request, then the task reframed with objective, context, constraints, source inputs and expected output. Keep the real screen readable.
30–45 s — Explanation: “La diferencia está en diseñar la tarea: qué entra, qué debe hacer la IA, qué debe revisar una persona y cómo sabemos si el resultado sirve.”
45–52 s — Result: show the resulting structured output and one visible verification criterion. “Ahora no solo estás usando ChatGPT: estás trabajando con IA.”
Final CTA: “Elige hoy una tarea real y estructúrala antes de pedirle una respuesta a la IA.”

### 20–35 s short variant
“Saber usar ChatGPT no significa saber trabajar con IA. Mira esta tarea: si solo escribes una pregunta, obtienes una respuesta. Si defines objetivo, contexto, restricciones y resultado esperado, conviertes la IA en parte de un proceso de trabajo verificable. Empieza por una tarea real, no por la herramienta.”

### Visual storyboard
1. 0–3 s: premium presenter/avatar or clean Cygnus opening + hook in large mobile-safe text.
2. 3–8 s: real work task screen, loose prompt highlighted.
3. 8–18 s: task is restructured; animate only objective/context/constraints/result labels.
4. 18–30 s: real AI-assisted execution/output, with punch-ins on evidence.
5. 30–45 s: simple process graphic: INPUT -> IA -> HUMAN QA -> VERIFIED RESULT.
6. 45–52 s: final real output/result criterion.
7. CTA card: one action only.

### Authentic evidence blocker
Required core proof: `F02_real_work_task_capture_v1`. It must be an owned/sanitized real task with no confidential client/account data. Until this exists, F02 cannot move to `EVIDENCE_READY` or final render certification.
